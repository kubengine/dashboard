## Pod 监控页挂载兼容修复

2026-11-18 在线上复现点击「查看 Pod 资源使用监控」后对 undefined 使用 `in` 的异常。原因是 SDK 原生 volumeMounts 不包含旧页面需要的 volume 定义。

后端现按挂载名称关联 spec.volumes，保留挂载路径、只读和 subPath，找不到卷时返回空对象；前端对缺失或异常 volume 安全降级，并识别 Projected、HostPath、DownwardAPI 和 CSI 来源。

SDK 专项回归 77 项通过，生产构建成功。已部署到 172.31.57.23，并验证原报错 Pod 的两张监控图、PVC/ConfigMap/Secret 来源及另一个使用 Projected 卷的 Pod 正常显示。通过浏览器精确替换详情响应，补充验证 undefined、null 与异常字符串卷信息不会使页面崩溃。
