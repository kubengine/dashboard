后端完整回归 412 项通过；最终 SDK 与 Pod 运维专项 121 项通过（含非阻塞分块传输、 UTF-8 跨帧、鉴权撤销、缺失 Shell 提示等）。新核心模块 mypy 通过；修改的 Python 文件 flake8 通过。

前端本轮文件格式检查通过，新模块无 TypeScript 错误。全量 tsc 仍有原有的 3 个错误，位于 Apps/Editor.tsx 和 Apps/FieldConfigGenerator.tsx，本轮未修改它们。

生产构建使用 xterm 官方 CommonJS 入口，避免当前 Webpack 对 ESM 继承链的错误摇树；压缩辅助函数隔离在 IIFE 内，并为静态文件添加版本哈希，避免部署更新时混用新旧分块。

当前没有 Windows Pod，Windows 文件脚本尚未实机验证；路径、参数编码与 Shell 选择分支已单测。
