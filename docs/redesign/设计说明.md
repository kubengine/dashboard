# KubeEngine 工作台整体改版

## 目标与设计依据

保持 React、Umi Max、Ant Design、TypeScript 技术栈和已有业务接口，重新设计品牌、导航、信息层级及页面视觉。通过 `skills/playwright-cli/SKILL.md` 对现有运行环境进行登录与只读巡检，覆盖资源、节点、应用与制品流程。

按 `skills/ui-ux-pro-max/SKILL.md` 执行整体设计系统检索，以及 React 表单定向检索。采用检索中适合基础设施控制台的 Minimalism / Swiss Style 和 Data-Dense Dashboard 原则。自动生成的营销页结构不适合本产品，未采用；产品领域检索没有核实到合适条目，导航结构基于现有功能与技能通用规则整理。React 建议仅采用适用于现有版本的受控表单与语义化交互，不引入 React 19 功能。

## 设计系统

- 主色：`#2563EB`；辅助色：青绿；深色导航：`#101E34`。
- 工作区背景：`#F4F7FB`；白色卡片；文字：`#172B4D` / `#596B83`。
- 状态使用文字与图标共同表达，成功、警告、错误分别使用绿、琥珀、红。
- 统一 8px 基础间距、8–10px 圆角；页面标题、区域标题、指标、说明文字形成明确层级。
- 数值使用本地等宽字体及等宽数字；正文使用操作系统中文字体。没有外网字体、图标 CDN 或其他新增运行时外网资源。
- Ant Design 令牌入口：`src/theme.ts`；布局与响应式样式：`src/global.less`。

## 品牌标识

新标识将六边形容器、立方体与 K 字形结合，以蓝色表现基础设施的稳定性，以青色角点表现连接。提供可缩放 SVG，适用于侧栏、折叠导航、登录页及浏览器图标。

- `public/assets/kubeengine-mark.svg`：方形图标。
- `public/assets/kubeengine-wordmark.svg`：横向标识。
- `public/assets/kubeengine-wordmark-light.svg`：用于深色背景的横向标识。
- `src/components/Brand.tsx`：深浅背景品牌组件，副标题为“容器云管理平台”。

SVG 是可编辑的项目原生矢量资产，不增加位图生成或运行时资源依赖。旧 PNG 文件保留供历史引用。

## 页面与交互

| 范围 | 改造内容 |
| --- | --- |
| 全局导航 | 深色分组菜单、工作空间说明、顶部面包屑、功能搜索、用户退出菜单、移动端导航 |
| 登录 | 双栏品牌介绍与账户表单、明确标签、自动填充、提交状态与失败提示 |
| 资源总览 | 等高指标卡、请求量与实际使用趋势区分、刷新与更新时间、节点搜索及展开详情 |
| 节点详情 | 统一页头、资源图表、元数据、系统信息、资源分配与节点状况，移除重复外层卡片 |
| 应用库 | 自适应应用卡片、正确图标比例、分类与名称搜索、服务端分页、加载/错误/空状态 |
| 应用配置 | 标准工具栏与表格、配置预览抽屉、分页数量及正确记录标识 |
| 注册与部署 | 统一标题、分步参数区域、可用的返回入口、明确提交含义 |
| 应用集群 | 状态表格、部署入口、名称搜索、实时更新及原有操作 |
| 制品管理 | 仓库、制品版本与详情的统一页头和表格布局，保留上传与删除确认 |
| 镜像导入 | 独立任务工作区、上传对话框、任务详情及原有进度/重试能力 |

节点表默认展示主要指标，CPU / 内存限制及标签通过展开行查看，节点详情入口保持可用。镜像导入和集群状态仍沿用现有接口与刷新机制。

## 可访问性与响应式

- 主要控件使用按钮或输入框；分类暴露 `aria-pressed`，标签展开暴露 `aria-expanded`。
- 为搜索、用户菜单与移动导航提供可访问名称；装饰图标不重复朗读。
- 保留可见焦点与“跳转到主要内容”入口；登录允许密码管理器及粘贴。
- 375、768、1024、1440px 为验收宽度；数据表在容器内横向滚动，卡片与工具栏自动重排。
- 遵循 `prefers-reduced-motion`；新图表关闭入场动画。

## 运行与验证

在 `dashboard/` 执行 `npm run dev` 或项目既有的 `pnpm dev`，本地预览为 `http://127.0.0.1:8000`。API 代理可由服务端环境变量 `KUBENGINE_API_TARGET` 指定，不会将登录凭据编入前端。

本地旧 MFSU 缓存包含 `/opt/dashboard` 路径。验证时清理生成缓存，并使用已被 Git 忽略的 `.umirc.local.ts` 临时设置 `mfsu: false`。生产配置保留原有 MFSU 设置。

验收记录见 [验证记录](验证记录.md)。截图位于 [screenshots](screenshots/)。本次不自动部署到客户环境。
